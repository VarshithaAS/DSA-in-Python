
# DSA Notes - Day 1

## 1. Big O Notation
Big O notation describes how an algorithm's time or space requirements grow as the input size increases.

## 2. Time Complexity
Time complexity describes how the amount of work grows with input size.

- O(1) - Constant time
- O(n) - Linear time
- O(n^2) - Quadratic time

## 3. Space Complexity
Space complexity describes how memory requirements grow with input size.

## 4. Auxiliary Space
Auxiliary space is the extra memory used by an algorithm to solve a problem.

- O(1) - Uses a fixed amount of extra space.
- O(n) - Extra space grows with input size.

## 5. Loop Examples
- One loop running n times: O(n)
- Two nested loops, each running n times: O(n^2)
- Nested loop where the inner loop runs i times: O(n^2)

## 6. What I Learned
- Big O notation
- Time complexity
- Space complexity
- Auxiliary space
- Single and nested loops
